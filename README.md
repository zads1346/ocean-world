# 潮汐之间 · Between the Tides

一片可以停留、也可以亲手掀起波浪的海。使用原生 HTML、CSS、JavaScript 和 WebGL 实时绘制，无外部运行依赖、无需构建。

## 功能

- 写实风格海面：多层波浪、海面法线、菲涅耳反射、浪尖泡沫与程序化天空
- 日夜时间滑杆与晨光、正午、落日、月夜预设；可开启时间缓慢流动
- 海面反光和雷暴强度调节，联动云层、雨、风浪及远处闪电
- 海浪高度 0.2×–3.0×
- 鼠标或触摸按住海面、滑动后松开，沿手势方向生成巨浪；速度与距离影响强度
- 最多四道同时传播的局部波浪，包含渐入、传播、衰减、寿命限制与相机安全高度
- 暂停、沉浸模式、全屏、可选择开启的合成海浪声与雷声
- 减弱动态和闪光、键盘可操作设置、移动端布局与自适应渲染分辨率

这是艺术化的实时海洋效果，不是科学流体模型。应用不使用分析追踪、外部网络服务或用户数据存储。

## 本地运行

需要支持 WebGL 的现代浏览器。若渲染失败，请检查浏览器硬件加速是否启用。

下载仓库后，在仓库根目录运行（需要 Python 3）：

```sh
python3 -m http.server 8000 --directory dist
```

然后在浏览器打开 <http://localhost:8000>。Windows 也可以将 `python3` 替换成 `py -3`。

也可使用任意静态 HTTP 服务器，直接把 `dist/` 作为网站根目录。`dist/` 中就是可编辑源码，不是需要重新编译的产物；项目没有 npm 安装或构建步骤。

## 操作

1. 点击「调一调大海」修改时间、浪高、反光、雷暴或画面质量。
2. 在可见海面按住鼠标左键或单指触摸，滑动后松开造浪。短点按不会造浪。
3. 用底部按钮暂停、开启声音或进入全屏；右下角眼睛按钮隐藏界面。
4. 需要更温和的体验时，开启「减弱动态与闪光」。

## 项目结构

- `dist/index.html`：页面、设置与控制按钮
- `dist/style.css`：界面样式与响应式布局
- `dist/ocean.js`：WebGL 着色器、天气、音频及交互
- `dist/waves.js`：共享的射线投影与定向波包计算
- `tests/waves.cjs`：波浪数学测试
- `tests/controls.cjs`：隔离的 JavaScript/模拟 DOM 与 GPU 读回测试
- `TESTING.md`：测试方式、实际覆盖和验收限制

## 检查

安装 Node.js 后，在仓库根目录运行：

```sh
node --check dist/ocean.js
node --check dist/waves.js
node tests/waves.cjs
node tests/controls.cjs
```

逻辑测试使用模拟 DOM 和 GPU 读回，不等同于真实浏览器、真机触摸或移动端性能验收。具体限制见 [TESTING.md](TESTING.md)。
